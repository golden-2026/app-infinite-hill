# Scholar pack: week one

There is one document for each path (christianity, catholicism, judaism, islam, hinduism, buddhism, sikhism and my-own-religion), and each one is written for that path's Keeper. Send each Keeper only their own file. Each file opens with a short thank-you and what we're asking. Then it walks through the seven week-one lessons in order: the story and its sources, every caption, every question with the right answer and why, what the guide teaches, and the "today" step. Each lesson ends with a numbered "Please confirm" list for the Keeper to mark as fine or correct. Before you send a file, look for any confirm item that mentions a picture (Islam, My own religion and a few others have them) and attach phone screenshots of those scenes, because the intro tells the Keeper the pictures come with the document. The seven Hindu lessons, plus "Let there be light" and "The son who came home" on the Christianity path, came without their own source notes, so we listed the sources those stories draw on. Ask those Keepers to check those lists especially. When answers come back, collect the corrections in one place, then have the lessons updated and checked again before anything goes live. The files are built from the lesson files in `prototypes/greybox/lessons/`, so if a lesson changes before you send its file, ask for the pack to be rebuilt.
