# hi-res overrides
Files here replace the image of the same key that `scripts/extract-design.mjs` pulls out of the design build.
Use them only when the source art (IH packs 3–6) is sharper than what the build embeds.

- `logo-mark.webp`: from IH pack 3 `art/logo/infinitehill_mark.png` (1254 px). Cropped to the artwork and framed like v175's embedded mark. 640 px wide.

Checked 2026-09-25: the 44 mascot poses in v175 are byte-identical to pack 3 `webp_720`, so there is nothing to override there.
The hill faces stay as embedded (780 px). Restacking the pack 4 panels would move the stones off the traced trail.
